# Java_labs

Лабораторные работы по дисциплине «Основы программирования» на языке Java.

Каждая лабораторная работа выполняется в отдельной ветке lrN, после чего оформляется Pull Request и ветка вливается в main обычным слиянием с созданием merge-коммита.

## Лабораторные работы

| № | Папка | Тема |
|---|-------|------|
| 1 | [1LR-C](1LR-C) | Консольное меню, ввод данных, ветвления и циклы |
| 2 | [2LR](2LR) | Массивы и матрицы |
| 3 | [3LR](3LR) | Строки, record и регулярные выражения |
